NutDiag – User Guide

NutDiag is a clinical decision-support and survey tool used to assess child nutrition status, classify malnutrition (SAM/MAM/Normal), and support field data collection.

Navigation Overview

The system has 5 main sections:

  • Wizard – Step-by-step diagnosis
  • ZScore – Quick WHZ calculation
  • BMI – For children 5–19 years
  • Survey – SMART data collection
  • Exports – View, download, and manage records

1. Wizard (IMAM-Based Clinical Assessment)

The Wizard is designed as a guided clinical workflow based on the IMAM Guidelines – Module 5: Identification and Classification of Wasting and Nutritional Oedema (6–59 months). It supports health workers to follow the correct steps for screening, classification, and decision-making.

Clinical Workflow (Aligned to IMAM Module 5)

  1. Step 1: Triage & Stabilisation
    - Identify danger signs using IMCI/ETAT principles - Determine if the child is clinically stabilised
    - Not stabilised → immediate referral for emergency care
  2. Step 2: Nutritional Assessment
    - Measure MUAC (cm) - Check for bilateral pitting oedema - (If needed) measure weight and height - Use Z-score (WHZ/WLZ) where required
  3. Step 3: Classification
    The system automatically classifies the child:
    • MUAC < 11.5 cm OR oedema → SAM
    • MUAC 11.5–12.5 cm → MAM
    • MUAC ≥ 12.5 cm → Normal
    • Z-score may upgrade severity (worst classification applies)
  4. Step 4: Appetite Test
    - Conducted for children with SAM or suspected complications - Pass: child eats adequately → may be managed outpatient - Fail: poor intake → indicates medical complications → inpatient care
  5. Step 5: Clinical Checks
    - Assess IMCI conditions and complications - Identify infections, metabolic problems, or severe illness
  6. Step 6: Risk Factors
    - Previous SAM - Relapsed MAM - Social or household risks - These influence treatment decisions
  7. Step 7: Decision & Care Path
    The system determines management:
    • SAM + complications / failed appetite → Inpatient care (ITC)
    • SAM uncomplicated → Outpatient care (OTP)
    • MAM → Supplementary feeding program
    • Normal → Routine care

Key Clinical Principles

  • Oedema automatically indicates Severe Acute Malnutrition (SAM)
  • Appetite test is critical to detect complicated SAM
  • The most severe indicator (MUAC, oedema, or Z-score) determines classification
  • Failed appetite = high risk → requires inpatient treatment
Critical Warning:
Children with:
  • Failed appetite test
  • Medical complications
  • Severe oedema (+++)
must be referred immediately for inpatient care.

What the System Does for You

  • Guides you step-by-step (no need to memorize protocol)
  • Automatically calculates Z-scores
  • Applies IMAM classification rules
  • Suggests appropriate care pathway
  • Ensures no critical step is skipped

Tip: Follow each step carefully and always review the final recommendation before saving.

2. Z-Score Page

Use this page for quick anthropometric assessment.

Steps:

  • Select child sex
  • Enter age (months)
  • Enter weight (kg) and height (cm)
  • Click Compute

Result:

  • WHZ score is calculated automatically
  • Classification is displayed:
    • WHZ < -3 → SAM
    • WHZ -2 to -3 → MAM
    • WHZ ≥ -2 → Normal

Results are saved for later export.

3. BMI for Age (5–19 Years)

Use this section for older children and adolescents.

  • Enter age, weight, and height
  • System calculates BMI-for-age
  • Provides classification (e.g. underweight, normal)

4. Survey (SMART Data Collection)

This section is used for household surveys and structured field data collection.

A. Location Setup

  • Select District → Sub-county → Parish → Village
  • All fields must be selected before saving

B. Household Information

  • Enter cluster number
  • Enter team number
  • Enter household ID
  • Select interview date

C. Child Data Entry

  • Add one or more children
  • For each child:
    • Select sex
    • Enter age (manual or via DOB)
    • Enter weight and height
    • Enter MUAC (mm)
    • Indicate oedema

D. Automatic Calculations

  • WHZ, WFA, and HFA are computed automatically
  • Status is classified as:
    • SAM
    • MAM
    • Normal

E. Saving & Workflow

  • Click Save Record to store data
  • Click Next Household to continue
Important: You must save before moving to the next household or data will be lost.

F. Export

  • Click Export ENA CSV to download survey data
  • Use “Reset Dataset” only when starting a new cluster

5. Exports / History

This section stores all previous assessments.

  • View all saved child records
  • Download data as CSV file
  • Share via WhatsApp
  • Clear all stored data if necessary
Tip: Export your data regularly to prevent data loss.

Data Power & Excel Reporting Capabilities

NutDiag is designed not only for assessment, but also as a high-impact data and reporting tool. All information collected across the Wizard, Z-Score, BMI, and Survey modules is consolidated into structured datasets that can be instantly exported and used in Excel for rapid analysis and decision-making.

Integrated Data Across All Modules

  • Clinical assessments (SAM, MAM, Normal)
  • Anthropometric measurements (MUAC, WHZ, BMI, etc.)
  • Appetite test and clinical indicators
  • Survey and household-level data
  • Geographical data (District → Village)

Why This is Powerful

  • One unified dataset – no need to compile data from different tools
  • Standardized format – ready for Excel, ENA SMART, or national systems
  • Real-time availability – no waiting for data entry or aggregation
  • Supports both clinical and survey workflows

Using the Data in Excel

After exporting CSV files, you can:

  • Create instant summaries (e.g. number of SAM, MAM cases)
  • Track trends over time (daily, weekly, cluster-level)
  • Compare locations or teams
  • Generate reports for districts, partners, or ministries
  • Prepare data for DHIS2, ENA SMART, or partner reporting tools

Typical Reporting Workflow

  1. Collect and save data in NutDiag (any module)
  2. Go to Exports and download CSV
  3. Open file in Excel
  4. Use filters or pivot tables to summarize results
  5. Generate tables, charts, or reports
Example Use Cases:
  • Daily OTC/ITC admission summaries
  • SMART survey cluster reporting
  • Facility-level nutrition dashboards
  • Rapid emergency response reporting
Best Practice:
Export and back up your data regularly (daily or per session) to ensure accurate reporting and prevent data loss.

Key Clinical Rules

  • MUAC < 11.5 cm → SAM
  • MUAC 11.5–12.5 cm → MAM
  • Oedema indicates SAM regardless of MUAC
  • Z-score is required when MUAC is borderline

Offline & Online Use

NutDiag is designed to function in both offline and online environments, making it suitable for use in remote field settings as well as health facility environments.

Offline Capability

  • All core modules (Wizard, ZScore, BMI, Survey) work after the app is loaded
  • You can enter, assess, and save data without continuous internet access
  • Data is stored locally on the device (browser storage)
  • Supports uninterrupted field work in low-connectivity areas
Field Advantage:
Once opened, NutDiag can be used continuously in remote areas without network coverage.

Online Capability

  • Required for initial loading of the application
  • Allows downloading (exporting) data and sharing reports
  • Supports backup and integration with cloud or program systems

Important Limitations (Flutter Web App)

  • Internet is required to open or reload the app (first access or after closing)
  • If the browser is refreshed without connectivity, the app may not load
  • Data is stored locally – clearing browser data or using another device will remove saved records
Important:
Always ensure you open the app while connected to the internet before going offline for field work. Regularly export and back up your data to prevent loss.

Recommended Workflow

  1. Open NutDiag while connected to the internet
  2. Proceed to field work and collect data offline
  3. Save all records during use
  4. When connected again, export CSV files
  5. Open in Excel and generate reports
Best Practices:
  • Always double-check measurements
  • Ensure correct age (critical for Z-score)
  • Save records immediately after assessment
  • Refer SAM cases without delay
